# 一言で

:::lead
2 つの列に共通する、順序を保った最も長い部分列を求める。その残りが、最も短い差分になる。
:::

- 扱うもの: 2 つの列。文字の列でも、ファイルの行の列でもよい。
- 使い道: 2 つのファイルの差分 (diff) を出す。変わらない行が共通部分列になる。
- 解き方の骨組み: 2 つの列の頭の部分ごとに、LCS の長さを表に埋める。表を右下から逆にたどると、LCS と差分が出る。

:::frame[この項目で使う数学]
- 部分問題の答えを表に残して使い回す解き方。まだなら先に [[M-04]]
:::

# 定式化

::::cols
:::col
### 一般形

列 $A = a_1 a_2 \cdots a_N$ と $B = b_1 b_2 \cdots b_M$ を考える。

- **部分列**: $A$ から 0 個以上の記号を消して得る列。残る記号の順序は変えない。
- **共通部分列**: $A$ の部分列で、$B$ の部分列でもある列。
- **最長共通部分列 (LCS)**: 共通部分列のうち、最も長いもの。その長さを $L$ と書く。
- **編集スクリプト**: $A$ を $B$ に変える、削除と挿入の命令の集まり。長さは、削除する記号と挿入する記号の数の和。最も短いものを **SES** と呼び、その長さを $D$ と書く。

$A$ の頭の $i$ 個と $B$ の頭の $j$ 個の LCS の長さを $L(i, j)$ と書く。求める値は $L = L(N, M)$。
:::
:::col

# 導出・証明 / 最適部分構造と漸化式

:::prop
$L(i, 0) = L(0, j) = 0$。$i, j \ge 1$ では次が成り立つ。

$$
L(i, j) =
\begin{cases}
L(i-1, j-1) + 1 & (a_i = b_j) \\
\max\bigl(L(i-1, j),\ L(i, j-1)\bigr) & (a_i \ne b_j)
\end{cases}
$$
:::

:::proof
$C = c_1 \cdots c_p$ を、$a_1 \cdots a_i$ と $b_1 \cdots b_j$ の LCS とする。

**$a_i = b_j$ の時。** $c_p = a_i$ にしてよい。この時 $c_1 \cdots c_{p-1}$ は、$a_1 \cdots a_{i-1}$ と $b_1 \cdots b_{j-1}$ の LCS になる。より長い共通部分列があれば、その後ろに $a_i$ を足して $C$ より長くできる。これは矛盾。よって $L(i, j) = L(i-1, j-1) + 1$。

**$a_i \ne b_j$ の時。** $c_p$ は $a_i$ と $b_j$ の両方にはなれない。$c_p$ が $a_i$ なら、$b_j$ は使われない。だから $C$ は $a_1 \cdots a_i$ と $b_1 \cdots b_{j-1}$ の共通部分列でもある。$c_p$ が $b_j$ なら、同じ理由で $a_1 \cdots a_{i-1}$ と $b_1 \cdots b_j$ の共通部分列。どちらでもなければ、どちらの場合にも入る。よって $L(i, j)$ は、$L(i-1, j)$ と $L(i, j-1)$ の大きい方。∎
:::

:::note[大きな問題の答えが、小さな問題の答えでできる]
$L(i, j)$ は、1 つ短い頭の部分の答えだけで決まる。これが [[M-04]] の表に残す解き方に合う。
:::

# 導出・証明 / 計算量と、表から LCS を戻す

:::prop
漸化式で表を埋めると、時間も場所も $O(NM)$ かかる。埋めた表があれば、LCS を $N + M$ 歩以内で戻せる。
:::

:::proof
**埋める。** マスは $(N+1)(M+1)$ 個ある。$i, j \ge 1$ のマスごとに、比べる判定を 1 回する。判定はちょうど $NM$ 回。1 回は定数の時間。表全体を残すので、場所も $O(NM)$。

**戻す。** $(N, M)$ から始める。$a_i = b_j$ なら $(i-1, j-1)$ へ斜めに進み、$a_i$ を LCS に入れる。違えば、$L(i-1, j)$ と $L(i, j-1)$ のうち大きい方へ進む。漸化式から、進んだ先の値で今の値が決まる。だから集めた記号は LCS になる。1 歩ごとに $i + j$ が 1 以上減る。よって歩数は $N + M$ 以下。∎
:::

:::note[例の数値で確かめる]
例では判定は $7 \times 6 = 42$ 回。戻る歩数は 9 で、$N + M = 13$ 以下。
:::

:::note[LCS は 1 つとは限らない]
例の LCS は $\texttt{BABA}$、$\texttt{CABA}$、$\texttt{CBBA}$ の 3 通り。長さはどれも 4。同じ値の 2 方向のどちらへ進むかで、出る LCS が変わる。
:::

# 導出・証明 / LCS と最短の編集は同じ問題

:::prop
削除と挿入だけを使う時、最も短い編集スクリプトの長さは $D = N + M - 2L$。
:::

:::proof
**LCS から編集へ。** 長さ $L$ の共通部分列を 1 つとる。$A$ のうち、それに入らない $N - L$ 個を消す。残りは共通部分列そのもの。次に、$B$ のうち、それに入らない $M - L$ 個を正しい場所に挿入する。これで $A$ は $B$ になる。長さは $(N - L) + (M - L)$。これは $N + M - 2L$ に等しい。

**編集から共通部分列へ。** $d$ 個を消し、$e$ 個を挿入する編集スクリプトをとる。消した後に $A$ に残る $N - d$ 個は、順序を保って $B$ に残る。だからこれは共通部分列で、長さ $\ell = N - d$。$B$ の長さから $M = \ell + e$。よって長さは $d + e = N + M - 2\ell$。

$N + M$ は決まっている。だから編集を最も短くすることは、$\ell$ を最も大きくすることと同じ。最大の $\ell$ は $L$。∎
:::

:::note[例の数値で確かめる]
$D = 7 + 6 - 2 \cdot 4 = 5$。削除は $N - L = 3$ 個、挿入は $M - L = 2$ 個。
:::

:::prop
$(0, 0)$ から $(N, M)$ への経路を 1 つ決めると、共通部分列 (trace) と編集スクリプトが 1 つ決まる。1 つの trace には、横と縦の辺の並びだけが違う経路が複数ある。斜めの辺の数は共通部分列の長さ。横と縦の辺の数は編集スクリプトの長さ。LCS は斜めの辺が最も多い経路。SES は横と縦の辺が最も少ない経路。
:::

横と縦の辺の重みを 1、斜めの辺の重みを 0 にする。すると、これは 1 つの始点からの最短経路の問題になる。

- **D-経路**: $(0, 0)$ から始まり、横と縦の辺をちょうど $D$ 本持つ経路。
- **対角線 $k$**: $x - y = k$ の点の集まり。

:::prop
**補題 1.** D-経路は、対角線 $k \in \{-D, -D+2, \dots, D\}$ の上で終わる。

**補題 2.** 対角線 $k$ で最も遠くまで行く D-経路は、次のどちらかで作れる。
- 対角線 $k-1$ で最も遠い $(D-1)$-経路、横の辺 1 本、続く最も長い斜めの辺の連なり。
- 対角線 $k+1$ で最も遠い $(D-1)$-経路、縦の辺 1 本、続く最も長い斜めの辺の連なり。
:::

:::proof
**補題 1.** 0-経路は斜めの辺だけなので、対角線 0 で終わる。横の辺は $k$ を 1 増やし、縦の辺は $k$ を 1 減らす。斜めの辺は $k$ を変えない。よって横か縦の辺を 1 本足すごとに、終わる $k$ の候補は $\pm 1$ ずれる。帰納法で補題 1 が出る。

**補題 2.** D-経路は、$(D-1)$-経路、横か縦の辺 1 本、斜めの辺の連なりでできている。最後の連なりが延ばせるなら、最も遠くはない。$(D-1)$-経路が最も遠くないなら、より遠いものに取り替えても同じ点に届く。∎
:::

$D = 0, 1, 2, \dots$ の順に、各対角線の最も遠い終点を補題 2 で求める。対角線 $N - M$ で $(N, M)$ に届いた時の $D$ が答え。時間は $O((N + M) D)$。

| $D$ | 対角線 $k$ と最も遠い終点 $(x, y)$ |
|---|---|
| 0 | $k=0$: (0, 0) |
| 1 | $k=-1$: (0, 1)、$k=1$: (1, 0) |
| 2 | $k=-2$: (2, 4)、$k=0$: (2, 2)、$k=2$: (3, 1) |
| 3 | $k=-3$: (3, 6)、$k=-1$: (4, 5)、$k=1$: (5, 4)、$k=3$: (5, 2) |
| 4 | $k=-2$: (4, 6)、$k=0$: (5, 5)、$k=2$: (7, 5)、$k=4$: (7, 3) |
| 5 | $k=-1$: (5, 6)、$k=1$: **(7, 6)** で終わる |

格子の外に出た終点は表から省いた。奇数の $D$ では、終点は奇数の $k$ だけにある。これは補題 1 のとおり。

:::note[見つかる LCS]
貪欲法の経路を戻ると、斜めの辺は (3, 1) (4, 3) (5, 4) (7, 5)。LCS は $\texttt{CABA}$。命令は「1D, 2D, 3IB, 6D, 7IC」。「xD」は $a_x$ の削除。「xIs」は $a_x$ の後ろへの $s$ の挿入。$x = 0$ は $a_1$ の前を表す。命令は $x$ の小さい順に並べる。
:::

# 導出・証明 / Hirschberg の方法: 場所を線形にする

$L(i, \cdot)$ の行は、$L(i-1, \cdot)$ の行だけで決まる。だから 2 行分の場所で、最後の行 $L(N, \cdot)$ を $O(NM)$ 時間で出せる。ただしこれだけでは LCS を戻せない。

:::prop
$L^*(i, j)$ を、$a_{i+1} \cdots a_N$ と $b_{j+1} \cdots b_M$ の LCS の長さとする。$0 \le i \le N$ の各 $i$ で、次が成り立つ。

$$
\max_{0 \le j \le M} \bigl( L(i, j) + L^*(i, j) \bigr) = L(N, M)
$$
:::

:::proof
LCS を 1 つとる。それを $a_i$ までの部分と、$a_{i+1}$ からの部分に分ける。前の部分が $b$ を $b_j$ まで使うとする。前の部分の長さは $L(i, j)$ 以下。後の部分の長さは $L^*(i, j)$ 以下。よって左辺は $L(N, M)$ 以上。逆に、どの $j$ でも、前後の共通部分列をつなぐと全体の共通部分列になる。よって左辺は $L(N, M)$ 以下。∎
:::

$A$ を $i = \lfloor N/2 \rfloor$ で分ける。前半を前から、後半を後ろから、最後の行だけ求める。和が最大になる $j$ で $B$ を分け、2 つの小さな問題を再帰で解く。時間は $O(NM)$ のまま、場所は $O(N + M)$ になる。

| $j$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $L(3, j)$ | 0 | 1 | 1 | 1 | 2 | 2 | 3 |
| $L^*(3, j)$ | 3 | 3 | 3 | 2 | 1 | 0 | 0 |
| 和 | 3 | **4** | **4** | 3 | 3 | 2 | 3 |

例では $i = \lfloor 7/2 \rfloor = 3$。和の最大は 4 で、$L(7, 6)$ と同じ。最大をとる最も小さい $j$ は 1。$B$ はここで分ける。

| $j$ \ $i$ | − | A | B | C | A | B | B | A |
|---|---|---|---|---|---|---|---|---|
| − | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| C | 0 | 0 | 0 | 1 | 1 | 1 | 1 | 1 |
| B | 0 | 0 | 1 | 1 | 1 | 2 | 2 | 2 |
| A | 0 | 1 | 1 | 1 | 2 | 2 | 2 | 3 |
| B | 0 | 1 | 2 | 2 | 2 | 3 | 3 | 3 |
| A | 0 | 1 | 2 | 2 | 3 | 3 | 3 | 4 |
| C | 0 | 1 | 2 | 3 | 3 | 3 | 3 | 4 |

埋め方の例を 2 つ挙げる。

- $L(3, 1)$: $a_3 = \texttt{C}$、$b_1 = \texttt{C}$ で等しい。$L(2, 0) + 1 = 1$。
- $L(5, 3)$: $a_5 = \texttt{B}$、$b_3 = \texttt{A}$ で違う。$\max(L(4, 3), L(5, 2)) = \max(2, 2) = 2$。

右下の値は $L(7, 6) = 4$。よって $L = 4$、$D = 7 + 6 - 8 = 5$。

# どこで使うか

- **ファイルの比較 (diff)**: 2 つのファイルを行の列と見る。変える行の数を最も少なくすることは、変わらない行の LCS を求めることと同じ。
- **diff の規格**: POSIX の diff は、file1 を file2 に変える変更の一覧を出す。この一覧は最小である「べき」(should) とされる。必ず最小とは書いていない。
- **実際の実装**: GNU diff の基本のアルゴリズムは Myers の方法 (1986)。`--minimal` を付けない時は、計算を抑える発見的な方法を使う。そのため、差分の多い大きな入力では、最小でない出力を出すことがある。
- **パッチ**: diff の出力を配れば、相手は `patch` でファイルを更新できる。差分がファイル全体より小さい時に特に役に立つ。
- **生物の配列の比較**: Hunt と McIlroy は、表を埋める解き方の出典に、アミノ酸の配列を比べる Needleman と Wunsch の方法 (1970) と、Sankoff (1972) を挙げる。

# 確かめる

例の数値で、紙に計算してから選ぶ。

:::quiz[問1]
$A$ は 7 個、$B$ は 6 個の記号を持つ。LCS の長さは 4。削除と挿入だけを数える時、最も短い編集スクリプトの長さはどれか。

- [ ] 3
- [x] 5
- [ ] 9

$D = N + M - 2L = 13 - 8 = 5$。3 は削除の数 $N - L$ だけ。9 は経路の辺の総数 $N + M - L$。
:::

:::quiz[問2]
Myers の編集グラフで、3-経路 (横と縦の辺がちょうど 3 本の経路) が終われる対角線はどれか。

- [ ] $k = 0$
- [ ] $k = 2$
- [x] $k = 3$

補題 1 から、終われるのは $k \in \{-3, -1, 1, 3\}$。0 と 2 は偶数なので入らない。
:::

:::quiz[問3]
長さ $N$ と $M$ の列の LCS を 1 つ求める。Hirschberg の方法は、表を全部埋める方法の何を良くするか。

- [ ] 時間を $O(NM)$ から $O(N + M)$ にする
- [x] 場所を $O(NM)$ から $O(N + M)$ にする。時間は $O(NM)$ のまま
- [ ] LCS をすべて見つける

前の行だけを持てば最後の行が出る。これと $L + L^*$ の定理で、半分に分けて再帰する。返す LCS は 1 つだけ。例では LCS が 3 通りある。
:::
